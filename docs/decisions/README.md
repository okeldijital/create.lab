Lightweight decision log for non-ADR operational choices.

## Purpose

Capture day-to-day engineering decisions that do not rise to the level of an
Architecture Decision Record, while remaining discoverable.

## When to use ADR instead

Use `docs/adr/` when the decision:

- Affects multiple packages or teams
- Changes architectural boundaries
- Establishes a permanent platform rule
- Requires alternatives analysis

See Platform Constitution Title IV — ADR Process.
